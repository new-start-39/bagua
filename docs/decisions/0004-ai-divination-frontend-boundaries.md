# ADR 0004：AI 解卦前端边界

## 状态

已接受，2026-08-21。

## 背景

现有应用通过根组件内部状态完成无需登录的欢迎、起卦和结果流程，并使用 localStorage 保存最近 10 条历史。新增 AI 解卦需要登录、注册、会话鉴权、可恢复的页面地址、指定卦象上下文和未来的服务端历史，但不能破坏匿名用户的现有能力。

## 决策

### 页面与鉴权

- 引入 Vue Router，为结果、登录、注册和 AI 对话建立独立路由。
- 现有起卦和结果浏览保持公开，只有 AI 路由要求登录。
- 鉴权使用 Cookie Session，前端不存储 token。
- 受保护路由通过异步守卫检查 Session，登录后只回跳到经过校验的站内路径。

### AI 上下文

- AI 解卦入口第一版只放在结果页。
- 历史记录先进入结果页，再使用同一入口，不在抽屉行内增加第二操作。
- 对话初始化必须绑定当前结果的 `castId`，不得把 localStorage 最新记录当作隐式上下文。
- 对话恢复和幂等去重只依据同一用户的同一个 `castId` 所代表的具体起卦记录，不依据本卦或变卦结果；不同 `castId` 即使卦象相同也建立独立对话。
- 前端向后端提交已经确定的本卦卦序与卦名，以及可选的变卦卦序与卦名；后端只校验其是否为六十四卦中的合法组合，不根据六爻复算或纠正卦象。
- 创建对话时允许原子地上传当前匿名卦象，不依赖完整历史合并。
- AI 消息固定使用 SSE：通过 `fetch()` 向消息接口发送 `POST`，解析 `text/event-stream` 响应，并使用 `AbortController` 停止生成；不采用原生 `EventSource`、NDJSON 或 WebSocket。

### 历史记录

- 匿名历史继续保存在 localStorage，维持最多 10 条。
- 登录账户历史以服务端为主，本地只作为即时缓存和待同步队列。
- 匿名历史不会在登录时无提示地全部上传；用户确认后才批量合并。
- 历史使用稳定 `clientId` 和 `schemaVersion`，服务端按用户和 `clientId` 幂等去重。

### 前端边界

- 页面组件只调用领域 API 模块，不直接散落网络请求。
- API 分为基础 HTTP、鉴权、卦象历史和 AI 对话四个边界。
- 没有后端时使用遵守同一契约的 Mock 适配器。
- 当前规模不强制引入大型状态库。
- 项目语言固定为 JavaScript，不引入 TypeScript；公共和可复用代码接口使用 JSDoc 记录参数、返回值、异常和共享数据结构。
- 免费 AI 由服务端实施用户与 IP 双维度的滚动配额、token 预算、并发和输入输出上限；前端只展示服务端结果，不承担可绕过的本地风控判定。

## 原因

- 路由可以可靠支持登录回跳、刷新、浏览器前进后退和直接访问。
- Cookie Session 降低前端处理长期凭据的责任，并符合已确定的登录方式。
- 明确 `castId` 可以防止用户查看历史旧卦时错误解读最新一卦。
- 以具体起卦记录而非卦象结果作为对话身份，可以让用户多次摇出相同卦象时分别询问不同事情。
- 前端是摇卦和定卦结果的来源，直接传输本卦与可选变卦可以避免后端重复实现一套定卦算法。
- 结果页统一入口保持历史抽屉简洁，并确保用户在进入 AI 前确认卦象。
- 混合历史兼顾匿名可用、跨设备账户体验、离线容错和隐私边界。
- 稳定 API 层允许前端先使用 Mock 开发，后续不需要重写页面逻辑。
- SSE 与现有单向 AI 回复流相匹配，并允许继续使用携带 JSON 消息体的 `POST` 接口。
- 以“主要回答是否需要结合当前卦象”为范围标准，可以容纳真实解卦的广泛分支，同时拒绝把免费接口当作通用内容生成服务。

## 影响

- `App.vue` 后续需要拆为应用外壳、路由页面和领域组件。
- 生产部署必须支持 HTML5 History 路由回退。
- 当前依赖 hash 的测试序列入口需要迁移。
- localStorage 历史需要从现有 `id` 结构迁移到 `clientId` 和版本化结构。
- 后端需要提供 Session、邮箱验证码、历史同步和 AI 对话接口。
- AI 输出必须继续遵守现有文化体验及高风险决策边界。

## 不采用的方案

### 所有页面都要求登录

违反现有无需登录即可起卦和查看结果的产品前提。

### 不引入路由，继续扩展根组件 phase

无法稳定处理登录回跳、刷新恢复、直接访问和浏览器历史。

### AI 始终读取 localStorage 最新记录

从历史打开旧卦时会发送错误上下文，也无法覆盖服务端历史和直接链接场景。

### 历史全部只存前端

账户无法跨设备使用，AI 会话和服务端卦象之间缺少稳定关联。

### 登录后自动上传所有匿名历史

匿名卦象可能带有隐私含义，共享设备场景下无提示上传不合适。

### 在历史抽屉每一行增加 AI 按钮

增加移动端误触和视觉噪声，且跳过了查看与确认卦象的步骤。

## 验证

- 路由测试覆盖公开路由、受保护路由、Session 未知状态、登录回跳和外部重定向拦截。
- 历史测试覆盖 v1 数据迁移、匿名上限、批量合并、幂等去重和退出后的缓存隔离。
- AI 测试覆盖当前结果、历史旧结果、记录缺失、同一 `castId` 重复初始化、不同 `castId` 得到相同卦象以及流式消息异常。
- 契约测试覆盖本卦必填、变卦可空、卦序与卦名合法组合，以及后端不复算前端摇卦结果。
- 视觉验收覆盖桌面与 375px 移动端的登录、注册、结果入口和 AI 对话页面。
- 完整实现后执行 `npm run ci`。
