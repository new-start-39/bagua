# 0003：使用 localStorage 保存卦象历史

## 决策

历史记录作为结果完成后的本地功能接入，入口放在顶部栏。记录最多保存 10 条，最新记录排在最前，超过上限时移除最旧记录。

## 数据边界

每条记录只保存起卦时间、唯一 ID 和六次爻值。打开历史记录时通过现有卦象计算函数重新生成本卦、变卦和动爻信息，避免重复存储展示数据。

## 影响

- 历史记录只属于当前浏览器和当前站点，不跨设备同步。
- 起卦过程不写入历史，只有六次完成并生成结果后才保存。
- 起卦页隐藏历史入口，避免中断未完成的流程。
- 存储数据损坏、不可用或超出容量时，当前会话仍可继续使用。

## 验证

`tests/history.test.mjs` 覆盖上限、先进先出、异常数据和 localStorage 读写行为；页面验收覆盖完成起卦、打开抽屉和历史回看。
